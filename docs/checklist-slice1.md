# 手机验收清单：切片 1（核心账本与月报）

> 在项目 M 已推送、已运行 `setupLedger`、已部署为“只有我自己”的网页之后，用 iPhone Safari 逐项检查。
> 以下数字都是**测试示例**，不是真实账目。建议选一个**没有真实账目的月份**做测试（例如下面写的 2026 年 1 月），做完后把测试账目全部删除。
> 每一项记录“通过 / 不通过 + 你看到的情况”。不通过时截图前请遮住地址栏。

**准备：** 打开记账网页，确认底部有“账目 / 记一笔 / 月报 / 设置”四个按钮，左上角有一个空的占位（以后放小助手）。

**附加检查（建议一起做）：**

- 删除与恢复：删除一笔测试账目 → 它从列表和月报中消失 → 设置 → 最近删除里能看到它和“自动清除”日期 → 点“恢复”后回到原月份。
- 退款：记一笔支出时勾选“这是退款”，在“关联的原交易”里选第 1 项的餐饮 120 → 类别自动变成“餐饮”；金额 20、日期 2026-02-03 → 2 月月报中“餐饮”显示 -$20.00（净退款），1 月餐饮仍为 $120.00。
- 设置页：“未分类”旁显示“系统类别”，没有删除按钮。
- 表格文字保持为文字：在电脑上打开「账本」表格的 `entries` 工作表（只看，不要修改），找到第 1 项那笔账的 `month_ny` 列：应显示 **2026-01**，单元格左对齐、是文字；点一下单元格，上方编辑栏显示 `2026-01`，而**不是**日期（例如 2026/1/1）。`occurred_at` 列也应是 `2026-01-10T17:00:00.000Z` 这样的文字。如果变成了日期，说明表格的“单引号文字”处理与预期不同，请截图（遮住网址）告诉 PM。

**收尾：** 把测试账目逐笔删除（它们会在“最近删除”保留 30 天后自动清除）。测试中新增的来源“兼职 A / 兼职 B”如不需要，可在设置中停用。
